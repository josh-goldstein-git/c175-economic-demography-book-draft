# Economic Demography — a companion to Econ/Demog C175 (draft)

**Read the book:** https://josh-goldstein-git.github.io/c175-economic-demography-book-draft/

An early, AI-assisted draft of a textbook companion to *Economic Demography* (Econ/Demog C175, UC Berkeley, Prof. Joshua R. Goldstein). Chapters follow the course lectures and labs, fleshed out with quotations and examples from the assigned readings. Margin tags mark material added beyond the course slides: **blue** = drawn from the readings, **orange** = new (framing, general knowledge, or analysis) and still under review.

This is a work in progress; errors are possible. Interactive "Try it" apps run in the browser (via Shinylive) from the HTML version.

## Contents of this repository
- `docs/` — the rendered book (served by GitHub Pages)
- `*.qmd`, `_quarto.yml`, `styles.css`, `_extensions/`, `tools/` — Quarto sources
- `data/` — public datasets used in figures (Human Mortality Database, UN WPP, World Bank, FRED, CDC, ACS/CPS extracts)
- `apps/`, `course_apps_extra/`, `images/apps/` — exported course Shiny apps and screenshots

To render: install Quarto and R, then `quarto render` (the book output goes to `_book/`).
